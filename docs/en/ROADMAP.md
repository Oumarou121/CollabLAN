# Roadmap — LocaLink

## Version 1.0 — Functional Foundation

- Network discovery
- Messaging (individual and group)
- File sharing
- Notifications
- Voice calls
- Audit log
- Administration and user management

## Version 1.1 — Improvements

- Improved groups
- Advanced search
- Performance optimization

## Version 2.0 — Extension

- Video calls
- Screen sharing
- Mobile application
- VPN
- Active Directory / LDAP integration
- Automatic updates

## Release Cycle

Features are developed on `feature/*` branches, validated, and then merged into `develop`. Once a coherent set of features has been validated, `develop` is merged into `main` to publish a new version. See [../CONTRIBUTING.md](../CONTRIBUTING.md) for the full workflow.

| Version | Stage |
|---|---|
| v0.1 | Project initialization |
| v0.5 | Core features |
| v0.9 | Beta version |
| v1.0 | First stable version |
