# Roadmap — CollabLAN

## Version 1.0 — Socle fonctionnel

- Découverte réseau
- Messagerie (individuelle et de groupe)
- Partage de fichiers
- Notifications
- Appels vocaux
- Journal d'audit
- Administration et gestion des utilisateurs

## Version 1.1 — Amélioration

- Amélioration des groupes
- Recherche avancée
- Optimisation des performances

## Version 2.0 — Extension

- Appels vidéo
- Partage d'écran
- Application mobile
- VPN
- Intégration Active Directory / LDAP
- Mises à jour automatiques

## Cycle de publication

Les fonctionnalités sont développées sur des branches `feature/*`, validées puis fusionnées dans `develop`. Une fois un ensemble cohérent de fonctionnalités validé, `develop` est fusionné dans `main` pour publier une nouvelle version. Voir [../CONTRIBUTING.md](../CONTRIBUTING.md) pour le détail du workflow.

| Version | Étape |
|---|---|
| v0.1 | Initialisation du projet |
| v0.5 | Fonctionnalités principales |
| v0.9 | Version bêta |
| v1.0 | Première version stable |
